# 🎮 Guess the Number Game

A simple command-line game written in Python. The computer has a secret number, and the player tries to guess it. After each guess, the game tells the player whether the secret number is higher or lower.

## 🚀 How to Run

1. Make sure Python 3 is installed.
2. Clone this repository or download the files.
3. Run the game:

```bash
python guess_game.py
```

## 🕹️ How to Play

* Enter a number from 1 to 100 when prompted.
* The game will tell you if the secret number is higher or lower.
* Keep guessing until you find the correct number.
* When you win, the game shows how many attempts you needed.
* The secret number is currently hardcoded as 42.

## 🛠️ Technologies

* Python 3.13
* Standard library only
